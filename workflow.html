StratForge Architecture & Build Notes

Technical breakdown of how C9 StratForge parses official GRID Series State JSON, projects telemetry onto real Riot VALORANT tactical minimaps across Ascent, Haven, and Split, computes deterministic setup win-rate deltas and Operator profiles, and runs automated Node + Playwright regression checks.

Runtime: Pure ESM (Node + Browser) Unit Tests: node:test (7/7) Maps: 3 Official Riot Minimaps (42 Callouts) E2E: Playwright 1440px + 390px

4-Stage Deterministic Pipeline

Shared ES modules power both Node unit tests and zero-build browser rendering.

Zero Runtime Hallucination
01 / Schema-First Parsing

Single Parser Path for Presets and Live Imports

Instead of maintaining separate mock shapes for UI demos, all three bundled presets emit official GRID GraphQL data.seriesState.games[].rounds[] payloads and run through parseGridSeriesState() on load. 

const raw = getRawPresetJson('c9-sen-ascent');
const match = parseGridSeriesState(raw);
02 / Coordinate Normalization

World Space to 0..1000 Official Riot Minimaps

Telemetry files arrive in raw engine units (-5200..6800) or normalized radar space (0..1000). normalizeCoordinate() auto-detects input bounds and maps directly onto calibrated Riot Ascent, Haven, and Split minimaps. 

if (rawX >= 0 && rawX <= 1000) return { x: rawX, y: rawY };
return mapWorldBoundsToRadar1000(spec.worldBounds, rawX, rawY);
03 / Deterministic Math

Reproducible Clustering & Vulnerability Scoring

Every scouting readout is deterministic: Euclidean centroid clustering (r = 64), deployed-vs-baseline setup win-rate delta, >=$4,700 vs glass-cannon Operator detection, and a 0-100 Trade-Death Vulnerability index. 

rawVuln = untradedRatio * 45 + glassCannonRate * 20
        + earlyPeekDeathRatio * 20 + midRoamPct * 15;
04 / JetBrains + Automated E2E

WebStorm Run Configs & Playwright Gate

The repo ships with .idea/workspace.xml run configs for the local ESM server and node --test. Before each deploy, scripts/verify-e2e.mjs validates zero console errors, Riot image loads, replay/draw controls, and 0px overflow at 1440px and 390px. 

npm test                    # 7/7 deterministic unit checks
node scripts/verify-e2e.mjs # headless Playwright audit

Engineering Takeaways

Production Lessons

Zero-build shared ES modules

Running the exact same src/maps.js, src/gridParser.js, and src/analytics.js files in Node tests and the browser kept test runs under 150ms and removed bundler friction in WebStorm.

AI in the build loop, deterministic math live

Coaches need auditable numbers during timeouts. Using AI tooling to architect and verify deterministic math delivers instant recalculation on dropped GRID JSON files with zero API latency or hallucination risk.

Visual & asset verification catches real bugs

Checking naturalWidth > 0 on every Riot minimap and agent portrait, font loads, and scrollWidth <= innerWidth in headless Chromium guarantees zero broken frames across desktop and mobile.
