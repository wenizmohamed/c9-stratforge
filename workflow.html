Engineering Takeaways

Production Lessons

Zero-build shared ES modules

Running the exact same src/maps.js, src/gridParser.js, and src/analytics.js files in Node tests and the browser kept test runs under 150ms and removed bundler friction in WebStorm.

AI in the build loop, deterministic math live

Coaches need auditable numbers during timeouts. Using AI tooling to architect and verify deterministic math delivers instant recalculation on dropped GRID JSON files with zero API latency or hallucination risk.

Visual & asset verification catches real bugs

Checking naturalWidth > 0 on every Riot minimap and agent portrait, font loads, and scrollWidth <= innerWidth in headless Chromium guarantees zero broken frames across desktop and mobile.
